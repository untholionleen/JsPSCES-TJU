## 2. 国际来源与当前接入方式

- NIST Chemistry WebBook SRD 69：公开物质页面与性质检索参考。网页目前仅提供来源入口，不声称已接入一个官方稳定通用 API。
- NIST ThermoML：混合物热物性与 VLE 实验数据的重要检索/导入候选。导入前要保留 DOI、出版来源和可再利用许可。
- IAPWS IF97：水和水蒸气的正式性质公式依据。项目提供的 `api/` 服务通过 CoolProp 的 `IF97::Water` 后端计算。
- CoolProp：开源物性计算库。网页首版没有把其全部纯物质数据复制成数据库；IF97 API 依赖 CoolProp Python 包。
- Phasepy：可作为 Python VLE/LLE/VLLE 计算与模型拟合服务的下一阶段引擎；本项目尚未部署 Phasepy 后端，因此不得宣称高压 VLE、γ-φ/φ-φ 全套求解已经连通。
- DDBST / Dortmund Data Bank：专业实验数据和模型参数补充来源，须按授权方式访问与导入。
- NIST REFPROP / TDE：适合专业校核，但需按许可获取；不随本项目公开包分发。

## 3. 数据必须区分的类型

1. 实测实验数据：保留实验条件、原始测量、实验方法、来源论文与 DOI。
2. 评价数据：注明评价机构、版本和选用标准。
3. 关联式：保存方程、系数、温压范围和单位。
4. EOS 参数：按具体 EOS 及 alpha 函数分开。
5. 二元交互参数：按组分对、模型、温度函数、数据集和拟合范围分开。
6. 模型预测结果：标识为 prediction，不与实验点混成一个数据系列。

## 4. 目前明确未完成的项目

- 未完成 NIST WebBook / ThermoML 自动批量采集与同步作业。
- 未部署 Phasepy VLE 后端和 NRTL/Wilson/UNIQUAC 参数数据库。
- 尚无已验证的 16 种物质全套 EOS 参数与全部混合物 kij。
- PRG、PRSV 在完成文献公式和参数独立校核前保持禁用。
- IF97 API 提供 T/P 单相性质及饱和端点服务；网页目前没有完整的所有 backward equations、区域自由度向导和双向反算界面。
- 附录8只嵌入精选节点，不包含完整教材附录表格，也不将其作为公开可再分发整表。
- 网站语言切换的第一版目前覆盖导航、首页主标题/说明；技术模块详情仍以中文为主。完整英文化需后续逐页翻译校核。

## 5. 发布前验证规则

- 每条可计算参数具备来源、物质身份、单位、有效范围和质量状态。
- 不允许因无 kij 或活度系数参数而自动填零。
- 结果记录输入状态、所选模型、根选择、数据源与计算引擎版本。
- VLE 图必须区别实验点、回归曲线和预测曲线。
- 国际来源暂不可达时，允许读取合法缓存，并显示最后同步时间与缓存版本。
