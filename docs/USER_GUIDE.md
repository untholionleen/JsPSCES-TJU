# TJU-ThermoHub v3.0 网页操作说明

## 1. 启动

解压整个项目文件夹，不能只单独下载 `index.html`。在项目根目录运行：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。Windows 用户也可双击 `start-local.bat`。不要使用 `file://` 方式直接打开。

## 2. 首页

首页用于介绍平台定位、四个计算/学习模块、建议学习路径和数据可信边界。主页卡片可直接跳转到相应模块。页脚注明项目为课程学习辅助用途，非天津大学官方发布。

## 3. 模块一：状态方程与热力学计算

### 3.1 纯物质 EOS

1. 选择物质。
2. 选择 vdW、RK、SRK 或 PR。
3. 输入温度 T（K）与压力 P（bar）。Tc（K）、Pc（MPa）、ω 从首批参考集填入，允许人工修改。
4. 点击计算。
5. 查看压缩因子 Z、摩尔体积、逸度系数、逸度及可用模型的剩余焓/熵，并检查全部可接受实根。

默认选最大可接受根作为气相候选；多根时保留其余根供学习检查。根的相态稳定性仍需进一步做等逸度/稳定性判断。PRG、PRSV 暂未开放，不应手工选择其他模型替代。

水的立方 EOS 只作为模型比较演示；水/蒸汽性质优先使用模块四的 IF97。

### 3.2 二元 PR 组元逸度

选择两个不同组分，输入 T、P、当前相组成与 kij。kij 输入框中的 0 是用户指定的教学假设，并不代表数据库中真实的二元交互参数。结果给出组元逸度系数和逸度；该计算不是完整泡点、露点或 TP Flash。

### 3.3 修正拉乌尔泡点/露点

输入两种组分的饱和蒸气压及活度系数。页面采用低压、气相近似理想假设，不会自动生成 NRTL/Wilson/UNIQUAC 参数。高压体系不要使用该简化结果代替 φ-φ EOS 法。

### 3.4 P-V-T 交互曲面

选择物质、模型和视图。拖动画布可旋转，滚轮可缩放；可切换三维视图以及 P-V、P-T、V-T 投影视图。曲线来自所选立方 EOS 的状态方程计算，不是实验测量数据。模型适用范围外的曲线点会被过滤。

## 4. 模块二：工程查表与普遍化关联

- Pitzer 第二维里关联：输入温度和压力，查看 Tr、Pr、B0、B1、B*、B 与截断 Z。低密度近似不能无条件外推到高压。
- 单位换算：支持压力、能量、体积、温度的常用单位换算。
- 来源注册表：打开 NIST WebBook、ThermoML、CoolProp、IAPWS、Phasepy 与 DDBST 官方资料入口。链接存在不代表平台已批量同步其数据。
- 教材工程图状态表：标识哪些图表等待授权数字化或由性质引擎生成。

## 5. 模块三：公式推导

左侧选择 D1—D11 专题，使用“上一步/下一步”阅读公式与文字说明。当前为教学提纲式推导展示；正式课程使用前，应将公式编号、页码、符号体系、推导假设与教师讲义逐一核对。

## 6. 模块四：水和水蒸气

### 6.1 教材附录插值轨

输入饱和温度 t（℃）和干度 x（0—1），查询当前精选表节点或相邻节点的线性插值，计算湿蒸汽 v、h、s。超出精选温度范围会提示错误。

该轨只包含精选可辨识节点，不是完整教材表格，也不是 IF97 方程直接计算结果。

### 6.2 IF97 标准性质轨

先部署 `api/` 服务并在“性质服务地址”中填写 API 根地址。输入 T（K）、P（MPa）可请求单相性质；输入饱和温度 T（K）可单独查询饱和液/汽端点。服务底层必须有 CoolProp 安装，并使用 `IF97::Water` 后端。

若 API 未启动、CORS 未放行、CoolProp 未安装或输入超出 IF97 有效范围，页面会显示错误，不会伪装成有效结果。

## 7. 模块五：数据附录与账户中心

- 16 种重点物质表显示 CAS、Tc、Pc 和 ω。未经国际来源逐条核验的条目保持 provisional。
- 术语表可通过搜索框筛选。
- 未登录时，计算可用，最近计算历史保存在当前浏览器 localStorage。
- 登录后，在 SQL 已部署且 RLS 正常的前提下，计算历史可写入 Supabase `thermo_calculation_history`。
- 注册用户默认 student；不能在个人资料中自行提升权限。

## 8. 登录、注册与找回密码

打开“登录 / 注册”窗口，选择登录、注册或找回密码。注册时提交邮箱、昵称和至少 8 位密码。打开 Supabase 发送的确认邮件，确认后返回部署站点登录。找回密码邮件会返回本站“设置新密码”表单。

邮箱确认/重置邮件能否送达取决于 Supabase Email Provider、Allowed Redirect URLs 和 SMTP 配置，具体见 `SUPABASE_AUTH_SETUP.md`。

## 9. 管理员与数据维护

管理员身份由 `thermo_profiles.role` 控制，不由前端邮箱判断。普通用户不能通过网页修改自己的角色。项目首期主数据维护可由项目所有者在 Supabase SQL Editor 中执行受控 SQL；管理员控制台和批量数据导入工具属于后续模块。
