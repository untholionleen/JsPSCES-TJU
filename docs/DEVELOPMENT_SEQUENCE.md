# TJU-ThermoHub 13.1.0 后续实际开发顺序与交付清单（最终执行版）

## 一、执行原则

1. 科学计算正确性优先于视觉效果；每个数值都必须标明模型、单位、输入域、数据状态和来源。
2. 核心计算本地化，网络仅用于账户与个人历史；Supabase 不可用时，学习和计算仍可使用。
3. 先完成可运行的主干，再按模块增加经验证的数据集；不以演示数据冒充真实物性。
4. 每个阶段都形成源代码、测试、说明文档与验收记录，不将“页面能打开”视为“科学功能已验收”。
