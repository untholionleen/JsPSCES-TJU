## 2. 模型与适用边界

| 模块 | 当前方法 | 已实现 | 未完成/限制 |
|---|---|---|---|
| 纯物质 EOS | vdW、RK、SRK、PR | 立方根、Z、V、φ、Hᴿ/Sᴿ估算、P–V 线 | 物质参数仍暂定；临界附近与根稳定性需扩展验证 |
| 二元 VLE | Wilson K + Rachford–Rice | 泡点/露点初估、等温闪蒸物料衡算 | 不是严格 φ–φ；尚未用实验二元数据拟合 kᵢⱼ |
| 水和水蒸气 | IAPWS-IF97 | 区域 1–5 基本方程、饱和线、Region 3 密度求根、P–h 教学反算 | Region 3 近临界求根、全部边界与全部反算组合仍需更广验证；尚未实现完整官方 backward equation 集 |
| 普遍化 Z | PR 对应态估算 | Tr、Pr、ω 输入与曲线 | 不等同于教材 Lee–Kesler 图；教材图数字化未完成 |
| 空气图 | 干空气定比热理想气体 | h–s 估算图 | 非真实空气多项式性质库，非湿空气心理图 |
| R-134a P–h | CSV 绘图器 | 数据导入与多序列绘图 | 未内置经审定数据文件；用户需提供经核验数据和来源 |
| 3D P–V–T | 立方型 EOS 网格 | 可旋转曲面 | 不是实验相图；多相不稳定根不代表真实相界 |

## 3. 数据状态

当前 Supabase `thermo_substances` 中 16 个基础物质的 Tc、Pc、ω 数据状态均为 `provisional`。前端 JSON 镜像保留此状态。参数必须按 CAS 号与 NIST / 权威来源逐项复核后才能标为 checked 或 approved。

## 4. 需要扩展的测试矩阵

- IF97 Region 1：低压/高压、温度边界 273.15 K、623.15 K；
- Region 2：低压高温、2a/2b/2c 边界、100 MPa 边界；
- Region 3：多个密度根、饱和液/汽支、临界点邻域、区域边界；
- Region 5：1073.15 K 与 2273.15 K 边界、50 MPa 上限；
- P–h：压缩液体、湿蒸汽、过热蒸汽、超临界状态；
- EOS：理想气体极限、临界点、多根区、无根区、氢气/水等偏离常规物质；
- VLE：不同二元体系、组成极限、压力温度求根不收敛、物料衡算残差；
- UI：窄屏、键盘操作、浏览器缓存升级、无网本地计算、Auth 网络失败。

## 5. 工程使用限制

本站现阶段定位为教学学习和初步工程估算工具。未经验证的关联、暂定物性、用户导入 CSV 和模型演示数据，不得作为工艺设计、安全分析、设备选型、生产控制或合规报告的唯一依据。
