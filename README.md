# 天津大学化工热力学学生自主学习网站

**TJU-ThermoHub · 13.1.0 · Nv3.1.0**

本仓库是面向化工热力学学习与工程辅助查询的静态网站。站点使用本地 JavaScript 引擎和数据，不依赖外部 CDN；本期不启用 Supabase、账户、OTP 或在线数据库。

## 已接入的主要功能

### 模块一：状态方程与热力学模型
- 纯物质 vdW、RK、SRK、PR 计算：求解 Z 根、摩尔体积、逸度系数、ln φ。
- EOS 剩余焓、剩余熵估算：通过 ln φ 的温度中心差分计算，属于数值导数估算；根切换附近结果需要谨慎使用。
- PR 立方方程混合物 φ–φ：经典二次/线性混合规则、Wilson K 初值、Rachford–Rice 闪蒸、泡点与露点压力。
- P-V、P-T、V-T 投影；亚临界纯物质两相等逸度平台和汽液共存线求解。
- 混合物当前采用用户输入的统一 kij，不含已按每个组分对拟合的二元参数数据库。

### 模块二：工程图表与普遍化关联
- Lee–Kesler 三参数对应态法：简单流体与参考流体修正 BWR 方程、体积根、ω/0.3978 插值，输出 Z、φ、ln φ、剩余焓与剩余熵。
- Lee–Kesler 纯流体约化曲线及 CSV。
- Pitzer 二阶维里低压近似计算。
- 空气 h–T、T–s 教学图：当前为常比热理想气体近似，不等同于高精度空气真实气体图。
- 理想气体 Cp 多项式积分计算器；二元 Margules/van Laar 活度系数计算器。

### 模块三：公式推导
- D1–D11 共 11 个专题、53 个分步讲解步骤，支持前进、后退、自动播放和关联模块跳转。
- 当前统一标为“待教师审核”，不表示已获课程教师或天津大学官方审定。

### 模块四：水与水蒸气性质
- 本地 IAPWS-IF97 五区域引擎：Region 1/2/3/5 正算、P-h/P-s/h-s 后向计算、Region 4 饱和关系。
- 饱和液体/蒸汽性质表、温度/压力查询、湿蒸汽干度关系、CSV 导出。
- 双线性和三点拉格朗日插值教学工具。
- IAPWS-IF97 引擎来源及许可见 `licenses/CC-BY-4.0-Neutrium-IAPWS97.txt` 和引擎头部注释。

### 附录
- 16 种纯物质基础临界参数和来源状态。
- 热力学符号、中英文术语、单位换算。
- 物性参数标记“待复核”的条目不得直接作为高精度设计输入。

## 验证

GitHub Actions 在每次 PR 和 main 更新时会检查：
- HTML 页面结构及离线资源文件。
- 内嵌应用、IF97、PR 混合物及 Lee–Kesler JavaScript 语法。
- IF97 五区/饱和线/后向方程参考点回归。
- 甲烷–乙烷闪蒸的物料衡算与逸度相等、泡点和露点。
- Lee–Kesler 公开教学参考点和趋势检查。
- 立方 EOS 两相等逸度共存压力测试。

测试通过说明代码和公开回归点符合设定容差，不代替浏览器人工验收、实验物性验证或工程审查。
