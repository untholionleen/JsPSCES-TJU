天津大学立方型状态方程求解系统 (JsPSCES-TJU)

本系统包含用于计算热力学性质和汽液相平衡条件的计算程序。软件旨在辅助教学——在展示计算结果的同时，清晰指明热力学性质的计算原理与过程。本系统已被全球多所知名高校及剑桥大学广泛应用于热力学课程教学。

关于本程序算法原理的简要描述发表于：P.J. Barrie, "JavaScript programs to calculate thermodynamic properties using cubic equations of state", Journal of Chemical Education, 82, 958-959 (2005)。

系统包含两大核心计算模块：

1. 纯物质立方型状态方程求解
  • 支持选择多种立方型状态方程（VDW、RK、SRK、PR、PR-Gasem），计算压缩因子、摩尔体积、逸度系数及离差函数。
  • 提供内置 16 种常见纯物质热力学临界参数数据库。
2. 二元混合物汽液相平衡预测 (VLE)
  • 支持泡点压力、泡点温度、露点压力、露点温度及等温汽液闪蒸计算。
  • 结合 van der Waals 混合规则与二元交互作用参数 $k_{12}$ 进行精确求解。

JavaScript Programs for Solving Cubic Equations of State Tianjin University (JsPSCES-TJU)

Here are two JavaScript programs for calculating thermodynamic properties and equilibrium conditions. They are designed to be educational - rather than just calculating the property, they indicate how the property is being calculated.

A brief description of these programs was reported in: P.J. Barrie, "JavaScript programs to calculate thermodynamic properties using cubic equations of state", Journal of Chemical Education, 82, 958-959 (2005).

The two main calculation modules are:

1. Solving cubic equations of state (pure substances)
  • Calculates compressibility factor, molar volume, fugacity coefficient and departure functions using various cubic equations of state.
  • Includes built-in database with critical parameters for 16 pure chemical substances.
2. Predicting vapour-liquid equilibrium of binary mixtures (VLE)
  • Calculates bubble point pressures/temperatures, dew point pressures/temperatures, and isothermal flash conditions.
  • Applies van der Waals one-fluid mixing rules with binary interaction parameters.
