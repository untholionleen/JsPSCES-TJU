Van der Waals equation (1873)

$$P = \frac{RT}{V - b} - \frac{a}{V^2}$$
$$a = \frac{27 R^2 T_c^2}{64 P_c}, \quad b = \frac{R T_c}{8 P_c}$$

First equation of state describing fluid properties over a wide pressure range.

Redlich-Kwong equation (1949)

$$P = \frac{RT}{V - b} - \frac{a}{T^{0.5} V (V + b)}$$

Soave-Redlich-Kwong (SRK) equation (1972)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b)}$$
$$\alpha(T,\omega) = \left(1 + m \left(1 - \sqrt{T_r}\right)\right)^2$$

Peng-Robinson equation (1976)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b) + b(V - b)}$$

Peng-Robinson-Gasem equation

Modified alpha formulation for extended fluid systems.

Critical Parameters Database

Contains 16 standard pure substances loaded with true thermodynamic critical values.

Solving Cubic Equations

Solves $Z^3 + c_2 Z^2 + c_1 Z + c_0 = 0$ for compressibility factor Z.

Advanced Thermodynamic Functions

Calculates fugacity coefficients and departure enthalpy/entropy.

Mixing Rules

VLE Calculation Types

Supports bubble point, dew point, and flash calculations.

Notation
