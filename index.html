JavaScript Programs for Solving Cubic Equations of State

这里包含用于计算热力学性质和平衡条件的 JavaScript 程序。程序旨在提供教学辅助——除了计算物性外，还能够直观展示相平衡与物性求解的推导逻辑。程序已被全球多家知名大学及剑桥大学广泛用于化工热力学教学。

关于本程序的详细学术背景发表于：P.J. Barrie, "JavaScript programs to calculate thermodynamic properties using cubic equations of state", Journal of Chemical Education, 82, 958-959 (2005). 在研究或教学引用时请注明该文献。

1. 纯物质立方型状态方程求解
  • 计算压缩因子 Z、摩尔体积 V、逸度系数及各类偏离函数。
  • 支持 5 种现代常用立方型状态方程（VDW, RK, SRK, PR, PRG）。
  • 内置 16 种常用纯物质的真实临界物性参数（Tc, Pc, ω）。
2. 二元混合物汽液平衡与闪蒸预测
  • 支持泡点压力/温度、露点压力/温度及等温汽液闪蒸计算。
  • 结合 Poynting 校正与 Rachford-Rice 质量平衡迭代方程。
  • 交互展示 P-x-y 及 T-x-y 相平衡二元相图。

Van der Waals 方程 (1873)

$$P = \frac{RT}{V - b} - \frac{a}{V^2}$$
$$a = \frac{27 R^2 T_c^2}{64 P_c}, \quad b = \frac{R T_c}{8 P_c}$$

第一个成功描述流体连续性及气液相变的立方型状态方程，虽然精度有限，但奠定了现代状态方程的基础。

Redlich-Kwong 方程 (1949)

$$P = \frac{RT}{V - b} - \frac{a}{T^{0.5} V (V + b)}$$

引入了与温度相关的引力项，极大提高了气体与液体密度预测精度。

Soave-Redlich-Kwong (SRK) 方程 (1972)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b)}$$
$$\alpha(T,\omega) = \left(1 + m \left(1 - \sqrt{T_r}\right)\right)^2$$

引入偏心因子 $\omega$ 项，显著提升了二元及多元碳氢化合物相平衡计算的准确性。

Peng-Robinson (PR) 方程 (1976)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b) + b(V - b)}$$

石油天然气工业中最广泛应用的状态方程，对临界点附近的液体摩尔体积计算具有很高的精度。

物性参数数据库

内置了 16 种经典化工纯物质的标准临界温度 $T_c$、临界压力 $P_c$ 及偏心因子 $\omega$ 真实数据。

二元混合规则

$$a_{\text{mix}} = \sum \sum x_i x_j \sqrt{a_i a_j}(1 - k_{ij}), \quad b_{\text{mix}} = \sum x_i b_i$$
