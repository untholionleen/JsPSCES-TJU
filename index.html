Van der Waals equation (1873)

$$P = \frac{RT}{V - b} - \frac{a}{V^2}$$
$$a = \frac{27 R^2 T_c^2}{64 P_c}, \quad b = \frac{R T_c}{8 P_c}$$

First equation to describe fluid properties over wide pressure ranges.

Redlich-Kwong equation (1949)

$$P = \frac{RT}{V - b} - \frac{a}{T^{0.5} V (V + b)}$$

Introduces temperature dependent attraction term for improved predictions.

Soave-Redlich-Kwong (SRK) equation (1972)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b)}$$
$$\alpha(T,\omega) = \left(1 + m \left(1 - \sqrt{T_r}\right)\right)^2$$

Peng-Robinson equation (1976)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b) + b(V - b)}$$

Peng-Robinson-Gasem equation

Modified alpha formulation for extended fluid systems.

Critical Parameters Database

16 standard pure chemical substances loaded with accurate thermodynamic constants.

Cubic Roots & Compressibility Factor

Solves $Z^3 + c_2 Z^2 + c_1 Z + c_0 = 0$. Smallest real root corresponds to liquid, largest to vapor.

Thermodynamic Departure Functions

Calculates fugacity coefficients and enthalpy/entropy departures via exact integration.

Mixing Rules

$$a_{\text{mix}} = \sum \sum x_i x_j \sqrt{a_i a_j}(1 - k_{ij})$$

VLE Calculation Types

Notation Methods
