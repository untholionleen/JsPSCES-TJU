立方型状态方程求解 JavaScript 程序

这里包含两个用于计算热力学性质与平衡条件的 JavaScript 程序。程序以教学为导向：除给出计算结果外，也展示性质的计算过程。原程序用于世界各地大学的热力学教学，并保留 Patrick Barrie 博士程序的教学传统。

相关程序介绍发表于：P.J. Barrie, “JavaScript programs to calculate thermodynamic properties using cubic equations of state”, Journal of Chemical Education, 82, 958–959 (2005)。

两个程序模块：

  • 计算压缩因子、摩尔体积、逸度系数及偏离函数，并提供多种立方型状态方程。
  • 保留原教学型 info 说明。
  • 说明：建议使用 Chrome、Firefox、Safari 或新版 Edge。
  • 支持泡点压力、露点压力、等温闪蒸，并保留 testing_5（BEST）的三类现代状态方程选择结构。

This page contains two JavaScript programs for thermodynamic properties and equilibrium calculations. They are educational programs: alongside the numerical result, they expose how the property is calculated, following the teaching tradition of Patrick Barrie’s original programs.

A brief description appeared in: P.J. Barrie, “JavaScript programs to calculate thermodynamic properties using cubic equations of state”, Journal of Chemical Education, 82, 958–959 (2005).

The two program modules are:

  • Calculate compressibility factor, molar volume, fugacity coefficient and departure functions using several cubic equations of state.
  • Retain the original educational info explanations.
  • Note: Chrome, Firefox, Safari or current Edge is recommended.
  • Supports bubble pressure, dew pressure and isothermal flash, while preserving the three-EOS structure from testing_5（BEST）.
