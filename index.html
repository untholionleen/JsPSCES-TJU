Here are two JavaScript programs that I wrote back in 2004 for calculating thermodynamic properties and equilibrium conditions. They are designed to be educational - rather than just calculating the property, they indicate how the property is being calculated. Remarkably the programs still work and have been used to assist the teaching of thermodynamics in various Universities around the world as well as Cambridge.

A brief description of these programs was reported in: P.J. Barrie, "JavaScript programs to calculate thermodynamic properties using cubic equations of state", Journal of Chemical Education, 82, 958-959 (2005). Please cite this paper if you get the chance!

The two programs are:

1. Solving cubic equations of state (pure substances)
  • This program calculates compressibility factor, molar volume, fugacity coefficient and departure functions using a choice of cubic equations of state.
  • Example problems that require use of this program.
2. Predicting vapour-liquid equilibrium of binary mixtures using cubic equations of state
  • NOTE: This program works fine with Chrome, Firefox and Safari. I think it works in Microsoft Edge, but it did not work in Internet Explorer versions 7-11.
  • This program calculates bubble point pressures and temperatures, dew point pressures and temperatures, and can do isothermal vapour-liquid flash calculations. The user may choose between three modern equations of state.
  • Example problems that require use of this program.

If the "info" help links don't work:

  • If the "info" links do not open, try holding down the CTRL key while clicking the link. If you are running software that disables all pop-up windows then you might not be able to read them.

Van der Waals equation (1873)

$$P = \frac{RT}{V - b} - \frac{a}{V^2}$$
$$a = \frac{27 R^2 T_c^2}{64 P_c}$$
$$b = \frac{R T_c}{8 P_c}$$

This was the first equation of state to describe the properties of fluids over a wide pressure range. It predicts the existence of a critical point, and also that liquids exist. While it is an improvement on the Ideal Gas law, it is still not particularly accurate.

Redlich-Kwong equation (1949)

$$P = \frac{RT}{V - b} - \frac{a}{T^{0.5} V (V + b)}$$
$$a = \frac{0.42748 R^2 T_c^{2.5}}{P_c}$$
$$b = \frac{0.08664 R T_c}{P_c}$$

An important two-parameter cubic equation of state that significantly improves liquid density and vapor pressure predictions over the Van der Waals equation by introducing a temperature-dependent attractive term.

Soave-Redlich-Kwong (SRK) equation (1972)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b)}$$
$$a(T) = a_c \alpha(T, \omega)$$
$$\alpha(T,\omega) = \left(1 + m \left(1 - \sqrt{T_r}\right)\right)^2$$
$$m = 0.48085 + 1.53400\omega - 0.11138\omega^2$$

Soave modified the Redlich-Kwong equation by replacing $T^{-0.5}$ with an alpha function dependent on temperature and acentric factor $\omega$, greatly improving vapor-liquid equilibrium (VLE) calculations.

Peng-Robinson equation (1976)

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b) + b(V - b)}$$
$$\alpha(T,\omega) = \left(1 + m \left(1 - \sqrt{T_r}\right)\right)^2$$
$$m = 0.37464 + 1.54226\omega - 0.26992\omega^2$$

Designed to provide better prediction of liquid molar volumes and VLE near the critical point, especially for hydrocarbon systems. Widely used in the oil and gas industry.

Peng-Robinson-Gasem equation

$$P = \frac{RT}{V - b} - \frac{a(T)}{V(V + b) + b(V - b)}$$
$$\text{Modified alpha formulation for extended fluid systems}$$

An optimized parameter set for the Peng-Robinson equation geared towards heavy hydrocarbons and gas mixtures with enhanced accuracy under supercritical conditions.

Critical Parameters Database

The dropdown menu contains 16 standard pure substances loaded with true thermodynamic critical temperature ($T_c$), critical pressure ($P_c$), and acentric factor ($\omega$) values sourced from standard physical chemistry databases.

Solving Cubic Equations

Cubic equations of state can be rearranged into a polynomial in terms of the compressibility factor $Z = \frac{PV}{RT}$. Depending on temperature and pressure, the equation can yield 1 real root or 3 real roots.

Advanced Thermodynamic Functions

Calculates fugacity coefficients ($\varphi$) and departure functions for enthalpy ($H^{\text{dep}}$) and entropy ($S^{\text{dep}}$) derived from Maxwell relations and exact integration of cubic equations of state.

Mixing Rules for Binary Mixtures

$$a_{\text{mix}} = \sum_i \sum_j x_i x_j a_{ij}, \quad a_{ij} = \sqrt{a_i a_j}(1 - k_{12})$$
$$b_{\text{mix}} = \sum_i x_i b_i$$

Standard van der Waals one-fluid mixing rules are applied with binary interaction parameter $k_{12}$ to model non-ideal mixture interactions.

VLE Calculation Types

Supports bubble point temperature/pressure, dew point temperature/pressure, and isothermal flash calculations using Rachford-Rice mass balance equations coupled with Poynting-corrected fugacity equilibrium criteria.

Notation and Thermodynamic Definitions

$z_1^{\text{overall}}$ is the overall feed mole fraction. $x_i$ and $y_i$ represent liquid and vapor phase mole fractions. $H^{\text{GM}}$ and $S^{\text{GM}}$ represent the molar mixing properties for ideal gas solutions.
