JavaScript Programs for Solving Cubic Equations of State - 天津大学定制版

天津大学立方型状态方程求解系统 (JsPSCES-TJU)

这里是 Patrick Barrie 博士于 2004 年编写的用于计算热力学性质和相平衡条件的 JavaScript 程序。这些程序的编写旨在用于教学目的——它们不仅计算热力学性质，还明确展示了性质的计算过程。这些程序至今仍运行良好，并被广泛用于剑桥大学及全球多所大学的热力学教学中。

关于这些程序的简要介绍发表于：P.J. Barrie, "JavaScript programs to calculate thermodynamic properties using cubic equations of state", Journal of Chemical Education, 82, 958-959 (2005)。如果您在学术工作中使用了本程序，请予以引用！

本系统包含以下两个主要计算程序：

1. 求解立方型状态方程（纯物质）
  • 本程序使用多种可选的立方型状态方程计算压缩因子、摩尔体积、逸度系数及残余函数（Departure Functions）。
  • 提供常见化学物质的标准临界参数数据库支持。
2. 使用立方型状态方程预测二元混合物的汽液平衡 (VLE)
  • 注意：本程序在 Chrome、Firefox 和 Safari 浏览器中运行顺畅。
  • 本程序可计算泡点压力、泡点温度、露点压力、露点温度，并可进行等温汽液闪蒸计算。用户可在三种现代状态方程之间进行选择。

关于“info”帮助链接：

点击各个参数旁的 “info” 链接可打开弹窗查看对应的详细理论公式推导及参数说明。
