LEARNING PATH

建议学习路径

学习
  1. 认识模型状态方程、临界常数、压缩因子和相态根。
  2. 理解性质逸度、剩余性质、焓熵变化和对应态关联。
  3. 进入相平衡活度系数、逸度系数、泡点/露点及实验数据。
  4. 工程应用蒸汽系统、制冷循环、过程能量衡算。

REGION-AWARE INPUT

区域与自由度说明

IF97 区域主要状态典型输入计划输出
Region 1压缩水 / 亚冷液体T、Pv、u、h、s、Cp、Cv
Region 2过热蒸汽T、Pv、u、h、s、Cp、Cv
Region 3高密度区 / 临界附近ρ、T 或 P、T 反算密度与性质反算
Region 4饱和曲线 / 湿蒸汽T 或 P；湿蒸汽另需干度 xPsat、Tsat、饱和液汽性质
Region 5高温蒸汽T、P高温区性质，严格限制有效范围

Region 4 的两相状态由一个独立强度变量确定；计算湿蒸汽性质时还需提供干度。超临界状态不简单等同于 Region 5。
